# AlQuds Wear — Website

This branch contains a simple, responsive static website scaffold for AlQuds Wear.

How to use

- Open index.html in a browser to view the site locally.
- To publish it, deploy to GitHub Pages (Settings → Pages) or any static host (Netlify, Vercel, etc.).

What I added

- index.html — landing page with hero, featured products, about, contact
- assets/css/styles.css — basic styles
- assets/js/script.js — small interactive behaviors
